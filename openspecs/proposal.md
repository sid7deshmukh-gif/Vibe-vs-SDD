# Proposal: Add CSV Export Button to Reports Page

## Why are we building this?
Users need to download report data to use in Excel or other tools.
Currently there is no way to export data from the reports page.

## What are we changing?
Adding a "Export CSV" button to the reports page that downloads 
the current report data as a .csv file.

## Expected Outcome
Users can click one button and get a downloaded CSV file 
with all the report data.
