# Vibe-vs-SDD

## What is this?
So basically this project is me trying out two different ways of coding the same thing.
One way is just vibing with AI and writing code without any planning,
and the other way is using something called OpenSpec where you plan everything first.

I built a simple Reports Page with a CSV export button in both ways.

---

## The Two Branches

### Vibe-coding
This is where I just opened the editor and started coding.
No planning, no docs, just went with the flow using AI.
It was faster to start but I kind of missed some things.

### Openspecs
This one I did properly. Before writing any code I made three files:
- proposal.md - why I am building this
- specs.md - what the app must do
- tasks.md - a checklist of what to build

Then I wrote the code based on those files.
The code came out better and covered more cases.

---

## What I noticed
The vibe coded version was quicker but it missed things like:
- disabling the button when there is no data
- putting today's date in the filename automatically

The openspec version had all of that because I planned it first.

---

## What is OpenSpec?
It's basically a way of planning your code before you write it.
You write down what you want to build, what it must do,
and a checklist. Then you code based on that plan.

---

## My Conclusion
Honestly vibe coding is fun and fast but spec driven development
gives you better results. I think for big projects OpenSpec makes
more sense because you don't miss requirements.
